Movie Hibernate

Учебный проект (JavaRush, Hibernate Module 2): маппинг Entity-классов на существующуюсхему БД movie и транзакционныебизнес-сценарии для проверки корректности маппинга.

MySQL Connector/J	8.0.33	JDBC-драйвер
